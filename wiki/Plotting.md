# Plotting

The active plotting entry point is [postprocess/plot_results.py](../postprocess/plot_results.py). It reads the CSV outputs created by the earlier stages and writes figure files under `figures/` by default.

## Active Plot Families

| Plot family | Function | Inputs | Output file stem |
|---|---|---|---|
| Sensor time series | `_plot_sensors` | `sensors/sensor_data.csv` | `sensor_velocity_<case>`, `sensor_pressure_<case>` |
| Force curves | `_plot_forces` | `forces/forces_<case>.csv` | `forces_<case>` |
| Force bars | `_plot_force_bars` | `forces/forces_summary.csv` | `force_bar_fx`, `force_bar_fy` |
| Rollout RMSE curves | `_plot_rmse` | `errors/cumulative_rmse_<case>.csv`, `errors/cumulative_rmse_mean.csv` | `rollout_error_<case>`, `rollout_error_mean` |
| Per-case RMSE bars | `_plot_rmse` | `errors/per_case_rmse.csv` | `per_case_rmse_bar` |

Comparison plots are generated by [postprocess/compare_models.py](../postprocess/compare_models.py), not by the single-model plotter.

## CLI Controls

| Argument | Effect |
|---|---|
| `--output_dir` | Writes figures to a custom folder instead of `output_dir/model_name/figures` |
| `--only` | Restricts output to `all`, `sensors`, `rmse`, or `forces` |
| `--sensor-drop-last-column` | Switches the sensor layout to 3x2 and crops the rightmost sensor column |

The plotting code also honors `sensor_drop_last_column` from the config file when the flag is not passed.

## Styling Defaults

| Setting | Value |
|---|---|
| Font family | `serif` |
| Figure formats | `png` |
| DPI | `300` |
| Sensor figure size | `(15, 7.5)` |
| Force figure size | `(10.5, 6)` |
| RMSE figure size | `(9.75, 5.25)` |
| Rollout x-range | `0` to `600` |
| Sensor layout | 3x3, or 3x2 when cropped |

## Sensor Panels

The sensor plots use a fixed wake layout ordered as `p1` through `p9`:

```text
top row:    p1 p2 p3
middle row: p4 p5 p6
bottom row: p7 p8 p9
```

When `sensor_drop_last_column` is enabled, the layout is cropped to the first two columns and the x-axis starts at rollout step 300.

## Comparison Plot Families

`compare_models.py` produces:

| Plot stem | Meaning |
|---|---|
| `compare_sensor_velocity_<case>` | Overlay of sensor velocity traces across models |
| `compare_sensor_pressure_<case>` | Overlay of sensor pressure traces across models |
| `compare_rollout_error_total` | Mean rollout RMSE across cases and models |
| `compare_rmse_bars` | Per-case RMSE grouped by model |
| `compare_force_bar_fx` / `compare_force_bar_fy` | Force summary bars grouped by case and model |

## Plotting Caveats

1. `plot_results.py` expects the CSV files written by the active pipeline, not the legacy `postprocess/metrics` layout.
2. The y-limits for sensor plots are hardcoded, so new physics fields may need a code change.
3. The rollout axis uses fixed ticks at 0, 100, 200, ..., 600.
